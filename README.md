# AMS PoliMe · Antibioticoterapia

PWA offline basata sui protocolli aziendali di terapia antibiotica: polmoniti (CAP/HAP/VAP), infezioni delle vie urinarie, infezioni di cute e tessuti molli (ABSSSI), infezioni gastrointestinali, sepsi e batteriemie, endocarditi e infezioni da CIED, infezioni del SNC. Strumento di consultazione: non sostituisce il giudizio clinico.
